## Implementation Comparison

### Python (xsdata)

**Location:** `crcl_python/`

**Approach:** Object-oriented inheritance
```python
# Base class
class JointDetailsType(DataThingType):
    pass

# Concrete implementations
class JointSpeedAccelType(JointDetailsType):
    joint_speed: Optional[float]
    joint_accel: Optional[float]

class JointForceTorqueType(JointDetailsType):
    setting: Optional[float]
    change_rate: Optional[float]

# Usage (polymorphism via inheritance)
actuate_joint = ActuateJointType(
    joint_number=0,
    joint_position=1.57,
    joint_details=JointSpeedAccelType(  # Pass subclass
        joint_speed=1.5,
        joint_accel=0.5
    )
)
```

**Pros:**
- Natural Python OOP style
- Duck typing makes it flexible
- IDE type hints work well
- xsdata handles XML/JSON serialization automatically

### Rust (serde)

**Location:** `crcl/src/commands.rs`

**Approach:** Functional enum with pattern matching
```rust
// Enum wrapper
pub enum JointDetails {
    SpeedAccel(JointSpeedAccelType),
    ForceTorque(JointForceTorqueType),
}

// Usage with speed/accel (explicit variant selection)
let actuate_joint = ActuateJointType {
    joint_number: 0,
    joint_position: 1.57,
    joint_details: Some(JointDetails::SpeedAccel(JointSpeedAccelType {
        joint_speed: Some(1.5),
        joint_accel: Some(0.5),
    })),
};

// Usage without joint_details (simple position command)
let actuate_joint = ActuateJointType {
    joint_number: 1,
    joint_position: -0.785,
    joint_details: None,  // No speed/accel constraints
};
```

**Pros:**
- Type-safe with compile-time guarantees
- Exhaustive pattern matching
- Zero-cost abstractions
- Custom deserializer auto-detects type from JSON fields

## How Type Detection Works

Both implementations use the **same strategy**: detect which type based on which fields are present in JSON.

**Python:**
```python
jd_data = aj_data.get("joint_details")

# Handle None case
if jd_data is None:
    joint_details = None
# Determine type based on fields present
elif "joint_speed" in jd_data or "joint_accel" in jd_data:
    joint_details = JointSpeedAccelType(...)
else:
    joint_details = JointForceTorqueType(...)
```

**Rust:**
```rust
// Custom deserializer in ActuateJointType
// The joint_details field is Option<JointDetails>
pub joint_details: Option<JointDetails>,

// When deserializing:
if joint_speed.is_some() || joint_accel.is_some() {
    Ok(Some(JointDetails::SpeedAccel(...)))
} else if setting.is_some() || change_rate.is_some() {
    Ok(Some(JointDetails::ForceTorque(...)))
} else {
    Ok(None)  // No joint details specified
}
```

## Practical Usage Patterns

### Pattern 1: Rust Producer → Python Consumer

**Rust side:**
```rust
let command = ActuateJointsType { /* ... */ };
let json = serde_json::to_string_pretty(&command)?;
std::fs::write("command.json", json)?;
```

**Python side:**
```python
with open("command.json") as f:
    data = json.load(f)

# Parse manually or use xsdata
command = parse_actuate_joints(data)
print(f"Received command {command.command_id}")
```

### Pattern 2: Python Producer → Rust Consumer

**Python side:**
```python
joint = JointStatusType(
    joint_number=0,
    joint_position=1.57,
    joint_velocity=0.5
)
json_data = json.dumps(asdict(joint))
with open("status.json", "w") as f:
    f.write(json_data)
```

**Rust side:**
```rust
let json = std::fs::read_to_string("status.json")?;
let joint: JointStatusType = serde_json::from_str(&json)?;
println!("Joint {}: pos={:?}", joint.joint_number, joint.joint_position);
```

### Pattern 3: TCP/Network Communication

Both sides can exchange messages over TCP using JSON:

**Rust server:**
```rust
let json = serde_json::to_string(&message)?;
stream.write_all(json.as_bytes())?;
```

**Python client:**
```python
json_data = socket.recv(4096)
message = json.loads(json_data)
```

## XML Support

Both implementations also support XML (though JSON is simpler for interop):

**Rust:** Uses `serde-xml-rs`
```rust
let xml = serde_xml_rs::to_string(&joint)?;
```

**Python:** Uses `xsdata` XML serializer
```python
from xsdata.formats.dataclass.serializers import XmlSerializer
serializer = XmlSerializer()
xml = serializer.render(joint)
```

## Performance Considerations

- **Rust:** Zero-copy deserialization, native speed
- **Python:** Good performance with xsdata (pure Python with C extensions)
- **JSON:** Slightly faster than XML for both
- **Recommendation:** Use JSON for network comms, XML for long-term storage/compliance
